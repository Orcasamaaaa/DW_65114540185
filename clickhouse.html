การติดตั้ง ClickHouse บน WSL (Ubuntu)

เพื่อให้สามารถจัดการกับข้อมูลขนาดใหญ่ในระบบ Data Warehouse ได้อย่างมีประสิทธิภาพ เราได้เลือกใช้ ClickHouse ซึ่งเป็น Column-oriented Database ที่มีความเร็วสูง โดยในที่นี้จะอธิบายวิธีการติดตั้งบนระบบ WSL (Ubuntu) อย่างละเอียด

ขั้นตอนที่ 1: อัปเดตแพ็กเกจในระบบ

เริ่มต้นด้วยการอัปเดตรายการแพ็กเกจและอัปเกรดซอฟต์แวร์ทั้งหมดให้เป็นเวอร์ชันล่าสุด

sudo apt update
sudo apt upgrade -y

ขั้นตอนที่ 2: ติดตั้ง ClickHouse

ใช้สคริปต์ทางการจาก ClickHouse เพื่อทำการติดตั้งโดยอัตโนมัติ คำสั่งนี้จะดาวน์โหลดและรันสคริปต์ติดตั้งให้ทันที

curl https://clickhouse.com/ | sh

ขั้นตอนที่ 3: เริ่มต้นใช้งาน ClickHouse

หลังติดตั้งเสร็จเรียบร้อย สามารถเริ่มเซิร์ฟเวอร์ในพื้นหลัง และเชื่อมต่อผ่าน client ได้ด้วยคำสั่งต่อไปนี้:

# เริ่ม server (แนะนำให้รันใน terminal แยก)
sudo /etc/init.d/clickhouse-server start

# เปิด client เพื่อสั่งงานฐานข้อมูล
clickhouse-client

🌐 พอร์ตที่ใช้งาน

  • 9000 – สำหรับ native client (เช่น clickhouse-client, ไดรเวอร์ต่างๆ)
  • 8123 – สำหรับ HTTP interface (ใช้กับ REST API หรือ Web UI)

📁 ไฟล์และโฟลเดอร์ที่สำคัญ

  • /etc/clickhouse-server/config.xml – ไฟล์ตั้งค่าหลักของเซิร์ฟเวอร์
  • /var/lib/clickhouse/ – โฟลเดอร์สำหรับจัดเก็บข้อมูลทั้งหมด
