🧭 การเชื่อมต่อ ClickHouse กับ Superset

คู่มือนี้จะแนะนำการเชื่อมต่อฐานข้อมูล ClickHouse ที่รันบน WSL เข้ากับ Apache Superset เพื่อสร้าง Dataset สำหรับการวิเคราะห์ข้อมูล

✅ 1. ตรวจสอบว่า Services ทำงานอยู่

  • Apache Superset ควรทำงานที่ http://127.0.0.1:8088
  • ClickHouse Server ควรตอบสนองที่พอร์ต 8123

ทดสอบ ClickHouse HTTP Port:

curl http://127.0.0.1:8123

หากถูกต้อง ควรได้รับข้อความตอบกลับว่า Ok.

✅ 2. เริ่มสร้างการเชื่อมต่อฐานข้อมูลใหม่

  • ไปที่หน้า Dashboard ของ Superset → เมนู Data > Databases
  • คลิกปุ่มสีเขียว [ + DATABASE ] ที่มุมขวาบน

✅ 3. กรอกข้อมูลการเชื่อมต่อ

ในหน้า Connect a database ให้กรอกข้อมูลดังนี้:

  • DATABASE NAME: ตั้งชื่อที่สื่อความหมาย เช่น ClickHouse_Local_WSL
  • SQLALCHEMY URI: กรอกค่าตามรูปแบบด้านล่าง

📌 SQLAlchemy URI สำหรับ ClickHouse

clickhouse+http://default:@localhost:8123/default

คำอธิบาย:

  • clickhouse+http: เชื่อมต่อผ่านโปรโตคอล HTTP
  • default:@: username:password (ค่าเริ่มต้นคือ user default ไม่มีรหัสผ่าน)
  • localhost:8123: ที่อยู่และพอร์ตของ ClickHouse server
  • /default: ชื่อฐานข้อมูล (สามารถเปลี่ยนตามที่สร้างไว้)

คลิก [ TEST CONNECTION ] → หากขึ้นว่า "Seems OK!" ให้กด [ CONNECT ]

✅ 4. เพิ่ม Dataset จากตาราง

  • ไปที่ Data > Datasets แล้วคลิกปุ่ม [ + DATASET ]
  • DATABASE: เลือก Database ที่สร้างไว้ เช่น ClickHouse_Local_WSL
  • SCHEMA: เลือก Schema (ค่าเริ่มต้นคือ default)
  • กด [ ADD ] เพื่อสร้าง Dataset

🎉 สำเร็จ!
