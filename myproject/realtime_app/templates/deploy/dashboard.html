📊 ขั้นตอนการนำเสนอข้อมูลบน Dashboard ด้วย Superset

ในส่วนนี้จะแนะนำวิธีสร้าง Dashboard ใน Apache Superset โดยจะยกตัวอย่างการสร้างกราฟจากตาราง mgbench.logs1 เพื่อดูค่า CPU Usage ตามเวลา

✅ ขั้นตอนที่ 1: เลือก Dataset

  • ไปที่เมนู Data > Datasets
  • เลือก Dataset ของตาราง mgbench.logs1
  • กดปุ่ม [ Explore ] เพื่อเข้าสู่หน้าการสร้าง Chart

✅ ขั้นตอนที่ 2: สร้างกราฟ CPU Usage (Line Chart)

เราจะสร้างกราฟแสดง ค่า CPU Idle (%) ตามเวลา จากตาราง mgbench.logs1

🎨 การตั้งค่าใน Superset

  • Chart Type: เลือก Line Chart
  • Time Column: ใช้ log_time
  • Metric: เลือกค่าเฉลี่ยของ cpu_idle (Average)
  • Group By: เลือก machine_group เพื่อเปรียบเทียบกลุ่มเครื่อง
  • ตั้งค่า Time Range: เลือกเป็น Last 7 days หรือกำหนดเอง

📌 ตัวอย่าง Query ที่ Superset จะสร้าง:

SELECT
    log_time,
    machine_group,
    avg(cpu_idle) AS avg_cpu_idle
FROM mgbench.logs1
GROUP BY log_time, machine_group
ORDER BY log_time ASC;

กราฟที่ได้จะแสดงการเปลี่ยนแปลงของ CPU Idle ตามเวลา แยกตามกลุ่มเครื่อง

✅ ขั้นตอนที่ 3: บันทึกและเพิ่มลง Dashboard

  • กดปุ่ม [ Save ] เพื่อบันทึก Chart
  • เลือก Add to existing dashboard หรือสร้าง Dashboard ใหม่
  • ตั้งชื่อ Dashboard เช่น MgBench Monitoring

🎉 สรุป

คุณได้เรียนรู้วิธีการสร้าง Line Chart จากตาราง mgbench.logs1 และเพิ่มลงใน Dashboard เพื่อใช้วิเคราะห์ประสิทธิภาพของระบบตามเวลา
