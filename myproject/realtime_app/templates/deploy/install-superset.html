ติดตั้งและเชื่อมต่อ Apache Superset บน WSL

⚙️ คู่มือนี้จะแนะนำขั้นตอนการติดตั้ง Apache Superset ซึ่งเป็นเครื่องมือ Business Intelligence (BI) แบบ Open-source สำหรับการสร้าง Dashboard และแสดงผลข้อมูล โดยจะติดตั้งบนระบบ WSL (Ubuntu)

ขั้นตอนที่ 1: เตรียมความพร้อมของระบบ

ติดตั้งแพ็กเกจที่จำเป็นสำหรับ Python และการคอมไพล์ รวมถึงอัปเดตระบบให้เป็นปัจจุบัน:

sudo apt update && sudo apt install build-essential libssl-dev libffi-dev python3-dev python3-pip python3-venv -y

จากนั้น อัปเกรด pip, setuptools และ wheel ให้เป็นเวอร์ชันล่าสุด:

pip install --upgrade pip setuptools wheel
pip install marshmallow==3.20.1

ขั้นตอนที่ 2: สร้าง Virtual Environment (แนะนำ)

การสร้างสภาพแวดล้อมเสมือน (Virtual Environment) จะช่วยแยกโปรเจกต์และ dependencies ต่างๆ ออกจากกัน:

# สร้างโฟลเดอร์ venv
python3 -m venv venv

# เปิดใช้งาน virtual environment
source venv/bin/activate

หมายเหตุ: หากเปิดใช้งาน venv สำเร็จ จะมีคำว่า (venv) แสดงอยู่หน้า command prompt

ขั้นตอนที่ 3: ติดตั้งและตั้งค่า Superset

ทำการติดตั้ง Apache Superset ด้วยคำสั่ง:

pip install apache-superset

# ติดตั้ง dependencies เผื่อ Pillow ไม่เจอ
pip install -r https://raw.githubusercontent.com/apache/superset/master/requirements/base.txt

จากนั้นสร้างไฟล์ superset_config.py และเพิ่ม SECRET_KEY:

nano ~/superset_config.py
import os
SECRET_KEY = os.getenv('SUPERSET_SECRET_KEY', 'YourSecretKey')

ตั้งค่า Environment Variable เพื่อให้ Superset ใช้ไฟล์ config:

echo "export SUPERSET_CONFIG_PATH=~/superset_config.py" >> ~/.bashrc
source ~/.bashrc

ขั้นตอนที่ 4: เตรียมฐานข้อมูลและสร้างผู้ดูแลระบบ

สร้างและอัปเกรดฐานข้อมูลภายในของ Superset (ใช้ SQLite เป็นค่าเริ่มต้น):

superset db upgrade

สร้างบัญชีผู้ดูแลระบบ (Admin):

superset fab create-admin

โหลดข้อมูลตัวอย่างและสร้าง Role พื้นฐาน:

superset init

ขั้นตอนที่ 5: เปิดใช้งาน Superset

รัน Web Server ของ Superset โดยใช้พอร์ต 8088:

superset run -h 0.0.0.0 -p 8088 --with-threads --reload --debugger

เมื่อเซิร์ฟเวอร์ทำงานแล้ว เปิดเว็บเบราว์เซอร์บน Windows ไปที่:

http://localhost:8088
