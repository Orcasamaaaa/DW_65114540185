📌 บทสรุปการบ้าน HW05: ClickHouse + Superset

สรุปขั้นตอนการทำงาน

  • ติดตั้ง ClickHouse บน WSL และตั้งค่า Server สำหรับจัดเก็บข้อมูล
  • นำเข้าข้อมูลจาก HW04 โดยใช้ Brown University Benchmark (MgBench)
  • ติดตั้งและตั้งค่า Apache Superset เพื่อใช้สร้าง Dashboard
  • เชื่อมต่อ Superset เข้ากับฐานข้อมูล ClickHouse ผ่าน SQLAlchemy URI
  • สร้าง Dashboard แสดงผลข้อมูล เช่น Line Chart และ Bar Chart จากตาราง mgbench.logs1

สิ่งที่ได้เรียนรู้

  • วิธีติดตั้งและใช้งาน ClickHouse สำหรับการจัดการข้อมูลขนาดใหญ่
  • การเชื่อมต่อ ClickHouse กับ Django และดึงข้อมูลจากฐานข้อมูล
  • การติดตั้งและตั้งค่า Apache Superset เพื่อสร้าง Dashboard วิเคราะห์ข้อมูล
  • การสร้าง Dataset และ Chart จาก SQL Query จริง
  • การนำข้อมูล Log มาวิเคราะห์ในรูปแบบ Visualization

ผลลัพธ์ของงาน

ผลงานสุดท้ายคือ Dashboard ที่สร้างขึ้นจากข้อมูลใน MgBench ซึ่งสามารถใช้ในการวิเคราะห์ประสิทธิภาพเครื่อง, ตรวจสอบ Log และแสดงผลข้อมูลในรูปแบบที่เข้าใจง่ายผ่านกราฟและ Visualization ต่างๆ
